Необходимо разграничить доступ к ресурсам кластера, исходя из организационной структуры компании.

- привилегированных групп пользователей
- группы есть право только на просмотр ресурсов кластера
- группа пользователей может настраивать кластер

| Роль  | Права роли | Группы пользователей |
| --- | --- | --- |
| Название роли, которое отвечает требованиям RBAC в Kubernets. | Укажите права, которые необходимо выдать этой роли. | Выделите группы пользователей в организации, которые нужно связать с этой ролью. |
| Root | * | Привилегированные пользователи, настривающие и управляющие в том числе. k8s кластером |
| Viewer | {apiGroups: ["*"], resources: ["*"], verbs: ["get", "list", "watch"]} | Разработчики/тестровщики приложений фирмы |
| Admin | *, но с ограничением на конктретный namspace | Администраторы сети, настривающие и управляющие в том числе. k8s кластером |
