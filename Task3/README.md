Задание 3.
На диаграмму контекста хорошо бы добавить подписи к связям и контекст мобильного приложения.
В требованиях стоит описать - где планируется аутентификация / авторизации пользователя.

## требования к безопасности
- каждая оценка номерв авто/фото пользователя сопровождается контрольной суммой, которая гарантирует, что данные не были изменены с момента их последнего обновления. 
- каждая оценка номерв авто/фото пользователя сопровождается цифровой подписью.
- передача всех сообщений происходит в зашифрованом виде 

## протоколы аутентификации и авторизации
- используем многофакторную аутентификацию
- Авторизация в системе строится по ролевой модели доступа RBAC

## взаимодействие между системами предприятия и внешней платформой.
- при передаче между компонентами системы с помощью шифрования SSL (Secure Sockets Layer) и TLS (Transport Layer Security)


## Аутентификация пользователя

**Где:**
- В инфраструктуре PropDevelopment
- Не у партнёра

**Как:**

* OAuth 2.1 + OpenID Connect
* Аутентификация выполняется:

  * при входе в мобильное приложение,
  * при обновлении access token.

* JWT Access Token
* User ID (UUID)
* Роли и атрибуты пользователя

---

### Авторизация пользователя

#### Уровень PropDevelopment

**Где:**

* `tenant-core-app`

**Что проверяется:**

* пользователь ↔ квартира,
* квартира ↔ дом,
* пользователь ↔ роль (собственник, член семьи, гость),
* пользователь ↔ разрешённые действия:

  * открыть дверь,
  * открыть шлагбаум,
  * просмотреть события.

* Проверка **перед каждым действием**

---

#### Уровень партнёра

**Где:**

* Платформа «Умный дом» партнёра

**Как:**

* Client Credentials Flow
* Scoped access tokens

**Важно:**

* партнёр **не знает конечного пользователя**,
* партнёр работает **только с идентификаторами устройств и объектов**.
